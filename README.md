# Office Helper Plugin

一个使用 Python 开发的办公自动化小助手。

支持：

- Excel处理
- 自动填写
- 文件整理
- 数据统计
- 批量处理
- 自动化操作

---

## 功能特点

✅ Excel自动读取  
✅ 批量文件处理  
✅ 自动生成报表  
✅ 简单易用  
✅ 支持Windows

---

## 运行环境

- Python 3.10+
- Windows 10 / 11

---

## 安装依赖

```bash
pip install -r requirements.txt
```

---

## 启动方法

```bash
python main.py
```
